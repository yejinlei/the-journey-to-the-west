# 西游奇谭 UI 重构计划 v0.9.3

## 背景与问题

用户反馈三大问题：
1. **图谱页（graph.html）**：节点文字过小、连线交错、信息密度过高、缺乏视觉引导
2. **首页（index.html）**：模块间距太小、标题层级不清、卡片拥挤
3. **正文评点（read.html）**：6 种评点颜色标签过多，视觉复杂

浏览器诊断确认：本体数据完整，问题在渲染层。

## 重构目标

参考"精致古籍网站"标准，实现：
- 图谱：节点可读、布局清晰、交互流畅
- 首页：呼吸感充足、层级分明、留白优雅
- 评点：颜色收敛、视觉降噪

## 改动范围

### P0: graph.html 图谱页重构（最痛）

**现状问题**：
- 手工拼接 SVG，环形布局算法简单
- 节点标签 12px、连线标签 10px，过小
- 349 条关系全部堆叠在一个环上

**重构方案**：
1. **布局算法升级**：环形 → 力导向布局（力模拟分离节点）
2. **节点尺寸**：标签 12px → 14px，节点半径按提及次数缩放
3. **交互增强**：
   - 滚轮缩放 + 拖拽平移
   - 悬停高亮关联节点
   - 点击节点显示详情卡片
4. **视觉降噪**：
   - 连线透明度降低，hover 时高亮
   - 默认只显示高 mention_count 的节点，其余可筛选展开

**关键文件**：
- `docs/graph.html` — 重写 SVG 渲染逻辑
- `docs/assets/app.css` — 新增图谱交互样式

### P1: index.html 首页留白优化

**现状问题**：
- `.grid` gap 仅 14px，卡片拥挤
- 标题层级（h2/h3）视觉区分度不足
- 模块间缺乏呼吸感

**重构方案**：
1. **间距系统**：gap 14px → 24px，卡片 padding 增大
2. **标题层级**：h2 加下划线装饰，h3 加左侧色条
3. **卡片质感**：增加 hover 微浮起效果，边框更细腻

**关键文件**：
- `docs/index.html` — 结构调整
- `docs/assets/app.css` — 间距/标题/卡片样式升级

### P2: read.html 评点颜色收敛

**现状问题**：
- 6 种评点类型各有一个标签：底端/侧批/夹批/眉批/引诗/底批
- 虽然颜色只有"朱批"和"墨批"两类，但标签文字不同，视觉上仍觉复杂

**重构方案**：
1. **颜色收敛**：6 色 → 3 色
   - 朱批（colophon/side/inline/top/bottom）→ 统一为"朱批"红色系
   - 墨批（caption）→ 保留"墨批"金色系
   - 新增"题款"（如需区分）→ 淡青色系
2. **标签简化**：chips 从 6 个 → 3 个（朱批/墨批/全部）
3. **类型筛选保留**：后端数据不变，前端展示收敛

**关键文件**：
- `docs/read.html` — TYPE_META 重构、chips 简化
- `docs/assets/app.css` — 颜色变量调整

## 实施步骤

1. **Step 1**：修改 `app.css` — 新增间距变量、标题样式、卡片升级、图谱交互样式
2. **Step 2**：重写 `graph.html` — 力导向布局、缩放交互、节点高亮
3. **Step 3**：调整 `index.html` — 结构微调以适配新样式
4. **Step 4**：简化 `read.html` — 评点类型收敛
5. **Step 5**：本地验证 → 提交 → 推送 gh-pages

## 验证标准

- [ ] graph.html：节点文字清晰可读（≥14px），连线不重叠，支持缩放
- [ ] index.html：卡片间有明显呼吸感，标题层级一眼可辨
- [ ] read.html：评点 chips ≤3 个，颜色体系简洁
- [ ] 全站：移动端（375px）可正常阅读

## 风险与回退

- 力导向布局性能：349 节点在浏览器端力模拟可能卡顿，备选方案是"层次布局+分页"
- 改动范围大：保留 git 历史，可快速回退到 v0.9.2
